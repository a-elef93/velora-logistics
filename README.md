# Velora Logistics

A premium logistics landing page built with plain HTML, CSS and JavaScript. Its central experience is a scroll-driven delivery journey: packages are prepared, enter the warehouse, travel by truck and arrive at the customer's home.

## Features

- Four-stage animated scrolling sequence
- Sticky cinematic backgrounds and package motion
- Responsive mobile navigation
- Services and contact sections
- Reduced-motion support
- No frameworks or JavaScript libraries

## Local preview

```bash
python3 -m http.server 4174
```

Then open `http://localhost:4174`.
